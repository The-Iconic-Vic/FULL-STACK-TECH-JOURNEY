## 🎯 Quick Reference Card

| Concept | Syntax |
|---------|--------|
| Root Layout | `app/layout.tsx` with `<html>` and `<body>` |
| Nested Layout | `app/folder/layout.tsx` |
| Client Navigation | `<Link href="/path">` |
| Active Link | `usePathname() === href` |
| Programmatic Nav | `router.push('/path')` |
| Server Redirect | `redirect('/path')` |
| Tailwind Class | `className="bg-blue-500"` |
| CSS Module | `import styles from './file.module.css'` |
